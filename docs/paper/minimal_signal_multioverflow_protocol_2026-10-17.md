# Exact multi-overflow telemetry audit: preregistered protocol

**Question.** In the existing per-expert clipping model, how many fixed-length
bits are necessary and sufficient to reproduce the next requested-feedback
gauge state when the admitted vector is fixed and there are multiple rejected
requests?

This is a controlled exact enumeration of the already stated T4b/T4c result.
It extends the previous `D=1` audit; it does not change the controller,
admission rule, or paper claim.

## Fixed family

For each `E in {2,3,4,8}` and `D in {1,2,3,4}`, use

- `K=1`, `T=E+D`, and `C_e=1` for every expert;
- uniform target `mu_e=1/E` and initial pressure `q=0`;
- per-expert admission `A_e=min(R_e,1)`;
- the exact requested update `q_next=Pi_g(q + R/T - mu)` and the admitted
  update with `A` substituted for `R`;
- every nonnegative integer vector `d` with `sum_e d_e=D`, setting
  `R=1+d`.

Each request vector is generated by `T` one-hot affinity rows: one token is
assigned to each expert and `d_e` additional tokens to expert `e`. This
constructs the declared Top-1 batch directly and uses deterministic lower-index
tie-breaking. All rational calculations are exact.

## Checks fixed before enumeration

For every `(E,D)` group, the script must enumerate exactly
`binomial(E+D-1,D)` request vectors and verify:

1. each constructed affinity batch routes to its declared `R`;
2. `sum(R)=T`, `A=(1,...,1)`, and `sum(R-A)=D`;
3. every world has the same admitted-feedback next gauge state;
4. requested-feedback next gauge states are pairwise distinct;
5. `P_0(R-A)` is pairwise distinct and therefore sufficient to recover the
   requested update on this fixed-`D` fiber;
6. the minimum fixed-length message size is exactly
   `ceil(log2 binomial(E+D-1,D))` bits.

Any failed check invalidates the affected group. There is no random seed,
statistical test, or tuned parameter.

## Interpretation boundary

The audit concerns zero-error emulation of this one requested-feedback update
over a known clipping fiber. It does not establish the minimum telemetry for
an overflow-optimal redesigned controller, a multi-round policy, or a real
communication implementation. In particular, these bit counts do not imply
that a production router pays for an additional collective; that marginal
systems cost must be measured in the target stack.
