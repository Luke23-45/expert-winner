# Facet-to-trajectory bridge experiment: preregistered protocol

**Status:** protocol fixed before execution. This is an exploratory synthetic
mechanism experiment in the existing deterministic Top-K, per-expert clipping,
gauge-pressure model. It does not replace the formal definition or test a
trained model.

## Question

The admitted-feedback facet theorem gives an exact local obstruction to a
convex potential: at a regular Top-K facet exchanging requests from expert
`i` to expert `j`, the admitted source decrease and destination increase must
match. The existing facet ensemble verifies this criterion locally. The
separate trajectory studies show that requested and admitted feedback can
produce opposite overflow rankings on particular plants.

This experiment asks whether a plant-level summary of the already-sampled
facet obstruction is associated with the closed-loop requested-versus-admitted
cumulative-overflow difference on the *same* affinity plants. It is a bridge
diagnostic, not a claim that local non-potentiality causes a particular
controller ranking.

## Fixed design

- Router: deterministic Top-2, `E=4`, `T=12`, fixed affinity batch repeated at
  each update. Use exactly the 40 integer-affinity plants generated by
  `run_admission_facet_ensemble.py` (`random.Random(seed)`, seeds `0..39`,
  each affinity entry independently uniform on `{-4,...,4}`).
- Exact arithmetic: `fractions.Fraction` for scores, counts, pressure,
  feedback, and accumulated cost. Ties use the existing lower-expert-index
  rule. The affinity generator and tie rule must match the facet audit.
- Pressure: `gamma=1`, `eta=1/10`, `delta=0`, uniform target, canonical
  min-coordinate gauge projection, and 120 updates. No gain search or
  post-result parameter adjustment.
- Admission: independent per-expert clipping only,
  `A_e=min(R_e,C_e)`. Capacity profiles are paired on every plant:
  `no_clipping=(12,12,12,12)`, `exact_total_uniform=(6,6,6,6)`,
  `exact_total_heterogeneous=(2,4,8,10)`, and
  `aggregate_shortage=(3,3,3,3)`.
- Feedback arms: requested `R`, admitted `A`, and no update. These are separate
  trajectories initialized at `q=0` on each same plant/profile.
- Primary trajectory outcome: cumulative overflow
  `sum_{t=0}^{119} sum_e (R_{t,e}-A_{t,e})`.
- Paired contrast: `D = overflow_admitted - overflow_requested` for each
  `(seed, capacity profile)`; positive values favor requested feedback on
  overflow, negative values favor admitted feedback. No weighted score.
- Geometry predictor: for each same `(seed, capacity profile)`, the fraction
  of regular facets marked mismatched in the existing exact facet-ensemble
  output. Facets are those sampled by that protocol; the fraction is not an
  unbiased estimate over the complete arrangement.
- Secondary trajectory records: final requested imbalance
  `||R-(KT/E)1||_1`, final pressure norm, number of route-change updates,
  first globally saturated state, and per-step overflow. These do not replace
  the primary outcome.

## Controls and exact assertions

1. Every step satisfies `sum_e R_e=K*T`, `A=min(R,C)`, and
   `sum_e(R_e-A_e)=K*T-sum_e A_e`.
2. In `no_clipping`, requested and admitted trajectories must be exactly
   identical, since `R=A` at every state.
3. If a uniform-capacity trajectory begins globally saturated, admitted
   feedback must remain at zero relative pressure update while that condition
   persists. The implementation must report whether the condition is met;
   it must not silently claim the control for unsaturated initial states.
4. Every `(seed, capacity profile, feedback)` arm must contain exactly 120
   states and 120 cost observations. Reconstruct the affinity arrays and
   compare their hashes with the existing facet-ensemble source.
5. A mismatch in any exact assertion invalidates that arm and must be resolved
   before scientific interpretation.

## Analysis fixed before execution

For each capacity profile, publish the 40 individual paired contrasts `D`,
their exact mean, median, minimum, maximum, and counts with `D<0`, `D=0`, and
`D>0`. Report the geometry-predictor values alongside them and compute
Spearman's rank correlation only when both variables vary. Treat the
correlation as descriptive: the plants are perturbations from one declared
small synthetic generator, facets are sampled rather than exhaustively
enumerated, and no population claim or causal claim is licensed.

The no-clipping arm is a negative control, not a target for significance
testing. A flat or weak geometry-to-overflow association is a valid result:
it would show that local non-potentiality alone is not a useful predictor of
the chosen closed-loop cost in this design. A strong association would motivate
a theorem attempt, but would not prove one.

## Interpretation boundary

This study tests the existing formal proportional-pressure law; it does not
pool it with the separate Megatron-style signed-bias integral controller. It
does not implement device-level score-ranked dropping, DeepSeek-V2's protected
sequences, learned router updates, GPU training, collective timing, or model
quality. The grouped-capacity pilot remains a separate model check. The result
cannot by itself establish benchmark separation or conference-level novelty.

## Reproduction

Run `python scripts/run_facet_trajectory_bridge.py` from the exploration
repository root. The script writes the complete exact-rational trajectory,
paired plant summary, geometry join, and configuration hashes under
`results/facet_trajectory_bridge/`.
